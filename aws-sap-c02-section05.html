1. S3 Architecture

Amazon S3 is an object storage service offering 11 nines (99.999999999%) of durability. Objects are stored across multiple devices in multiple AZs within a Region by default.

S3 ARCHITECTURE ┌─────────────────────────────────────────────────────────┐ │ S3 BUCKET │ │ Region: us-east-1 │ Bucket Name: my-app-data │ │ │ │ Object Key: /uploads/2024/01/report.pdf │ │ ┌──────────────────────────────────────────────┐ │ │ │ Metadata (system + user-defined) │ │ │ │ Storage Class (Standard, IA, Glacier...) │ │ │ │ Encryption (SSE-S3, SSE-KMS, SSE-C) │ │ │ │ Version ID (if versioning enabled) │ │ │ │ ETag (MD5 of object data) │ │ │ │ Object Lock (Compliance/Governance/Legal) │ │ │ └──────────────────────────────────────────────┘ │ │ │ │ Durability: 11 nines (11x9s) = 99.999999999% │ │ Availability: 99.99% (Standard) │ │ Max object size: 5 TB │ │ Multipart upload recommended for > 100 MB │ └─────────────────────────────────────────────────────────┘

S3 Key Concepts

  • Objects = key + value (data) + metadata + version ID
  • Bucket names globally unique across ALL AWS accounts
  • Maximum object size: 5 TB; single PUT max: 5 GB
  • For objects > 100 MB, use multipart upload (required for > 5 GB)
  • S3 is a Regional service, not global (despite global namespace)
  • Strong consistency for all operations (since Dec 2020)
  • Unlimited storage — no pre-provisioning needed

3. S3 Lifecycle Policies

S3 LIFECYCLE POLICY EXAMPLE Object Created → S3 Standard (0-30 days, hot data) → S3 Standard-IA (30-90 days, cooling) → S3 Glacier Instant Retrieval (90-365 days) → S3 Glacier Deep Archive (365+ days) → Delete (after 7 years for compliance) COST EXAMPLE (1 TB of data): Standard: $23/month Standard-IA: $12.50/month (after 30 days) Glacier Flexible: $3.60/month (after 90 days) Deep Archive: $0.99/month (after 1 year) Annual savings vs keeping everything in Standard: ~$260/TB

Lifecycle Rule Actions

  • Transition: Move objects to cheaper storage class after N days
  • Expiration: Delete objects after N days (or delete expired delete markers)
  • Abort incomplete multipart uploads: Clean up partial uploads after N days
  • Can apply to entire bucket or specific prefix/tag
  • Minimum days before transitioning from Standard to IA: 30 days

5. S3 Object Lock & Compliance

S3 OBJECT LOCK MODES GOVERNANCE MODE: • Users with s3:BypassGovernanceRetention CAN delete/modify • Protects against accidental deletion • Use for: internal policies, data governance COMPLIANCE MODE: • NO user (including root) can delete/modify until retention period expires • Cannot shorten retention period • Use for: regulatory compliance, FINRA, SEC, HIPAA LEGAL HOLD: • No retention period — indefinite protection • Any user with s3:PutObjectLegalHold can add/remove • Use for: litigation holds, active investigations

7. EFS (Elastic File System)

Amazon EFS is a fully managed, scalable NFS (Network File System) that can be mounted by thousands of EC2 instances simultaneously across multiple AZs.

FeatureEFS StandardEFS One Zone
AZ redundancyMulti-AZ (Regional)Single AZ
Cost$0.30/GB-month$0.16/GB-month
Use caseProduction shared filesystems, CMS, CI/CDDev/test, single AZ workloads

EFS Storage Classes

  • EFS Standard: Hot data, frequent access
  • EFS Standard-Infrequent Access (IA): Moved after 30/60/90 days; retrieval fee
  • EFS Intelligent-Tiering: Auto-move to IA when not accessed, back to Standard when accessed

10. DataSync & Transfer Family

AWS DataSync

Fast, automated, online data transfer service — moves large amounts of data between on-premises storage and AWS storage services.

  • Up to 10x faster than open-source tools
  • Source: NFS, SMB shares, HDFS, S3 API endpoints, Azure Blob
  • Destination: S3, EFS, FSx for Windows, FSx for Lustre, FSx for OpenZFS, FSx for ONTAP
  • Scheduled or on-demand transfers with data integrity verification
  • Agent runs on-premises (VM); no agent needed for S3-to-S3 transfers

AWS Transfer Family

Fully managed file transfer service supporting SFTP, FTPS, and FTP protocols, backed by S3 or EFS.

  • Enables partners/customers to transfer files using familiar SFTP without changing their workflows
  • Integrates with existing SFTP clients — transparent to end users
  • Authentication: Service-managed (passwords/SSH keys), AWS Directory Service, custom identity provider (Lambda)
  • Files land in S3 or EFS — trigger Lambda for processing

DataSync vs Storage Gateway vs Transfer Family

  • DataSync: One-time or scheduled bulk data migration/sync. Fastest for moving large datasets.
  • Storage Gateway: Ongoing hybrid connectivity — on-prem apps access cloud storage as if local.
  • Transfer Family: Partner/customer file transfers using SFTP/FTP — familiar protocol, S3 backend.
  • Snow Family: Physical device for petabyte-scale offline migration.

S3 CLI Examples

# Enable versioning
aws s3api put-bucket-versioning \
  --bucket my-bucket \
  --versioning-configuration Status=Enabled

# Configure lifecycle policy
aws s3api put-bucket-lifecycle-configuration \
  --bucket my-bucket \
  --lifecycle-configuration '{
    "Rules": [{
      "ID": "MoveToGlacier",
      "Status": "Enabled",
      "Filter": {"Prefix": "logs/"},
      "Transitions": [
        {"Days": 30, "StorageClass": "STANDARD_IA"},
        {"Days": 90, "StorageClass": "GLACIER"}
      ],
      "Expiration": {"Days": 2555}
    }]
  }'

# Enable Cross-Region Replication
aws s3api put-bucket-replication \
  --bucket source-bucket \
  --replication-configuration '{
    "Role": "arn:aws:iam::123:role/replication-role",
    "Rules": [{
      "Status": "Enabled",
      "Destination": {
        "Bucket": "arn:aws:s3:::dest-bucket-eu-west-1",
        "StorageClass": "STANDARD_IA"
      }
    }]
  }'

# Enable Object Lock in Compliance mode
aws s3api put-object-legal-hold \
  --bucket regulated-data-bucket \
  --key financial-report-2024.pdf \
  --legal-hold '{"Status": "ON"}'

  bucket = aws_s3_bucket.data.id
  rule {
    apply_server_side_encryption_by_default {
      sse_algorithm     = "aws:kms"
      kms_master_key_id = aws_kms_key.s3_key.arn
    }
    bucket_key_enabled = true  # Reduces KMS API calls by 99%
  }
}

resource "aws_s3_bucket_lifecycle_configuration" "data" {
  bucket = aws_s3_bucket.data.id
  rule {
    id     = "tiering"
    status = "Enabled"
    transition {
      days          = 30
      storage_class = "STANDARD_IA"
    }
    transition {
      days          = 90
      storage_class = "GLACIER_IR"
    }
    expiration {
      days = 2555  # 7 years
    }
  }
}

resource "aws_s3_bucket_object_lock_configuration" "data" {
  bucket              = aws_s3_bucket.data.id
  object_lock_enabled = "Enabled"
  rule {
    default_retention {
      mode  = "COMPLIANCE"
      years = 7
    }
  }

11. Exam Tips & Cheat Sheet

SAP-C02 Storage — Critical Points

  • S3 durability 11 nines: Even One Zone-IA has 11 nines durability WITHIN the AZ — it's AZ-level availability that's lower (99.5%).
  • Glacier retrieval: Instant = milliseconds. Flexible = minutes to hours. Deep Archive = up to 12 hours.
  • Replication not retroactive: Must use S3 Batch Operations or copy scripts for existing objects.
  • Object Lock Compliance: No one can delete/modify — not even root. Governance mode: admins can bypass.
  • EBS is AZ-specific. Cannot attach to EC2 in different AZ. Snapshot → copy to another region/AZ.
  • EFS vs EBS: EFS = shared (NFS, multiple instances). EBS = block, one instance (except io2 Multi-Attach).
  • FSx Lustre: HPC, ML, high throughput. Can use S3 as backing store.
  • FSx Windows: SMB protocol, Active Directory integration. Windows workloads.
  • Storage Gateway File: NFS/SMB on-prem backed by S3. For ongoing hybrid access.
  • DataSync: Fast one-time or scheduled migration. Not for ongoing hybrid access.
  • Transfer Family: SFTP/FTP clients → S3 or EFS. Existing partner workflows unchanged.
  • S3 Intelligent-Tiering: Monitoring fee per object. Best for unknown/variable access patterns.
Storage Class Selection
  • Frequent: Standard
  • Unknown pattern: Intelligent-Tiering
  • Infrequent, fast: Standard-IA
  • Archive, immediate: Glacier IR
  • Archive, flexible: Glacier Flexible
  • Compliance archive: Deep Archive
  • Reproducible, 1 AZ: One Zone-IA
Block vs Object vs File
  • EBS: Block, 1 EC2, AZ-specific
  • Instance Store: Block, temp, ephemeral
  • S3: Object, internet-accessible, unlimited
  • EFS: File (NFS), many EC2, regional
  • FSx Windows: File (SMB), AD integrated
  • FSx Lustre: File, HPC/ML
Migration Tools
  • DataSync: online bulk transfer
  • Snowball Edge: offline, TBs–PBs
  • Storage Gateway: ongoing hybrid
  • Transfer Family: SFTP protocols
  • S3 Batch Ops: process existing objects
S3 Security
  • SSE-S3: AWS manages keys
  • SSE-KMS: customer CMK, audit in CloudTrail
  • SSE-C: you provide key per request
  • DSSE-KMS: double encryption
  • OAC: CloudFront → S3 (preferred over OAI)
