Mock Exam 1 — Foundations & Core Architecture

75 Questions 180 Minutes Domain Focus: All domains Difficulty: Mixed
Q1
A company is using AWS Organizations and wants to prevent any member account from leaving the organization. Which SCP achieves this?
  • A) Deny organizations:CreateAccount
  • B) Deny organizations:LeaveOrganization
  • C) Deny organizations:DeleteOrganization
  • D) Deny organizations:RemoveAccountFromOrganization on the management account
Show Answer
B. LeaveOrganization is the API action a member account uses to exit. Denying it via SCP prevents self-removal.
Q2
An EC2 instance needs to call AWS APIs without using access keys. What mechanism provides temporary credentials automatically?
  • A) IAM User with environment variables
  • B) IAM Instance Profile (attached IAM Role)
  • C) AWS Secrets Manager with auto-rotation
  • D) EC2 Key Pair
Show Answer
B. Instance Profile attaches an IAM Role to EC2. The instance metadata service (IMDS) provides auto-rotating temporary credentials via STS. No keys stored on the instance.
Q3
A company needs to store session state for a web application running on 10 EC2 instances behind an ALB. Users should NOT be bound to a specific instance. What is the BEST solution?
  • A) Enable sticky sessions on the ALB
  • B) Store session state on EC2 instance local disk
  • C) Store session state in Amazon ElastiCache for Redis
  • D) Use EBS volumes shared via EFS for session state
Show Answer
C. ElastiCache Redis provides shared, in-memory session storage accessible by all instances. Enables stateless EC2 design — any instance can serve any request. Low-latency reads for session data.
Q4
A Lambda function processes messages from an SQS queue. The function fails with a timeout on 5% of messages. These failed messages keep reappearing. How should the architect address this? (Select TWO)
  • A) Configure a Dead Letter Queue (DLQ) on the SQS queue to capture messages that fail after the maximum receive count
  • B) Enable SQS long polling to reduce empty receives
  • C) Increase the Lambda function timeout and set maxReceiveCount on the SQS queue to limit retries before moving to DLQ
  • D) Enable SQS FIFO to prevent duplicate processing
Show Answer
A and C. DLQ captures poison-pill messages that consistently fail. maxReceiveCount limits retry attempts. Increasing timeout addresses legitimate timeouts. This prevents infinite retry loops on bad messages.
Q5
A company wants to host a static website on S3 with a custom domain and HTTPS. Which services should be used together?
  • A) S3 Static Website Hosting + Route 53 + EC2 SSL termination
  • B) S3 + API Gateway + ACM
  • C) S3 Static Website Hosting + CloudFront + ACM (us-east-1 certificate) + Route 53
  • D) S3 + AWS WAF + Route 53
Show Answer
C. S3 natively doesn't support HTTPS for custom domains. CloudFront provides HTTPS termination using an ACM certificate (must be in us-east-1 for CloudFront). Route 53 routes the custom domain to CloudFront.
Q6
A company is experiencing unpredictable bursts of traffic to their RDS MySQL database, causing CPU to spike to 100%. Read queries are 80% of the load. What should the architect implement?
  • A) Upgrade to a larger RDS instance (scale up)
  • B) Enable RDS Multi-AZ
  • C) Add RDS Read Replicas and update application read connections to use the replica endpoint
  • D) Enable RDS automated backups with faster restore
Show Answer
C. Read Replicas offload 80% read traffic from the primary. Applications read from replica endpoint, write to primary endpoint. Up to 5 RDS read replicas or 15 Aurora replicas supported.
Q7
An application stores files in S3. The company must ensure files cannot be deleted for 7 years for compliance. Even administrators should not be able to delete the files during this period. Which S3 feature should be enabled?
  • A) S3 Versioning with MFA Delete
  • B) S3 Object Lock in Compliance Mode with a 7-year retention period
  • C) S3 Object Lock in Governance Mode
  • D) S3 Bucket Policy denying s3:DeleteObject
Show Answer
B. Object Lock Compliance Mode: retention period cannot be shortened or removed — not even by the root account or AWS Support. Governance Mode allows privileged users to bypass retention. Bucket Policy deny can be overridden by root.
Q8
A company wants to run a containerized application without managing servers. The containers run for 15 minutes on demand, triggered by API calls. Which is the MOST cost-effective and operationally simple solution?
  • A) ECS on EC2 with Auto Scaling
  • B) ECS on AWS Fargate
  • C) EKS with managed node groups
  • D) EC2 instances running Docker
Show Answer
B. Fargate is serverless containers — no EC2 management. Pay per task vCPU/memory per second. Perfect for on-demand, 15-minute tasks. No node management, no cluster scaling concerns.
Q9
A company uses a third-party SaaS service and wants to receive real-time events from it (webhooks) and route them to different internal services based on event type. Which architecture requires the LEAST custom code?
  • A) API Gateway → Lambda → SQS → consumer Lambdas
  • B) Amazon EventBridge with a partner event source from the SaaS vendor, and rules routing to Lambda, SQS, or Step Functions based on event patterns
  • C) Kinesis Data Streams → Lambda routing function
  • D) SNS topic → multiple Lambda subscribers
Show Answer
B. EventBridge has native SaaS partner integrations (Shopify, Datadog, Salesforce, etc.). Rules with content-based filtering route events to different targets. Zero routing code needed — all configuration-driven.
Q10
A company's CloudFormation stack deployment takes 45 minutes. They want to detect and roll back failed deployments automatically, including detecting application-level failures (not just resource provisioning failures). Which feature enables this?
  • A) CloudFormation Stack Policies
  • B) CloudFormation Rollback Triggers using CloudWatch Alarms
  • C) CloudFormation Drift Detection
  • D) CloudFormation Change Sets
Show Answer
B. Rollback Triggers allow specifying CloudWatch Alarm ARNs. During/after deployment, if the alarm fires (e.g., high error rate, failed health checks), CloudFormation automatically rolls back to the previous state — detecting app-level failures, not just provisioning errors.

Mock Exam 2 — Networking & Security Focus

75 Questions 180 Minutes Focus: VPC, IAM, Security Services, Compliance Difficulty: Medium-Hard
Q1
A company has VPCs in us-east-1 and eu-west-1. Developers in us-east-1 need to SSH into EC2 instances in eu-west-1 through an internal bastion without going through the internet. Which solution provides this WITHOUT creating internet-routable paths?
  • A) VPC Peering + NAT Gateway
  • B) Transit Gateway with inter-region peering between us-east-1 TGW and eu-west-1 TGW
  • C) CloudFront with Lambda@Edge
  • D) VPN connection between us-east-1 and eu-west-1
Show Answer
B. TGW inter-region peering connects TGWs in different regions over the AWS backbone network (private, not internet). VPCs attach to their regional TGW and can route to the peer TGW's VPCs. No internet exposure.
Q2
A security team wants to block all traffic from specific known-malicious IP ranges at the VPC level, not just at individual instances. Which service and rule type should they use?
  • A) Security Groups with deny rules for each malicious IP
  • B) Network ACLs (NACLs) with explicit DENY rules for the malicious IP ranges
  • C) AWS WAF with IP match conditions
  • D) AWS Shield Advanced with proactive response
Show Answer
B. NACLs are stateless, subnet-level firewalls that support explicit DENY rules. Security Groups are stateful and do NOT support explicit deny — only allow rules. WAF operates at Layer 7 HTTP, not VPC level. NACLs block traffic before it reaches any resource in the subnet.
Q3
A company wants to enforce that all new IAM roles created in any member account have a Permission Boundary set. If a role is created without a boundary, it should be automatically remediated. What achieves this with LEAST custom code?
  • A) AWS Config rule (iam-role-managed-policy-check) with SSM Automation document for auto-remediation that attaches the Permission Boundary policy
  • B) AWS CloudTrail → CloudWatch Events → Lambda function to check and attach boundary
  • C) An SCP denying iam:CreateRole without an attached Permission Boundary (using condition key)
  • D) AWS Security Hub custom finding with Lambda remediation
Show Answer
A. Config with SSM Automation auto-remediation is the most operationally simple. Config detects the non-compliant role, SSM Automation runs to attach the boundary — all configurable without custom code. Option C (SCP with iam:PermissionsBoundary condition) is also valid as a preventative control but requires careful SCP crafting.

Mock Exam 3 — Database & Storage Deep Dive

75 Questions 180 Minutes Focus: RDS, Aurora, DynamoDB, S3, EBS, EFS, Migration Difficulty: Hard
Q1
An application writes 1 KB items to DynamoDB. The table has 500 WCU provisioned. A sudden 3x traffic spike causes ProvisionedThroughputExceeded errors. The team needs an immediate, temporary fix with ZERO code changes and minimal cost. What should they do?
  • A) Switch to DynamoDB On-Demand mode immediately
  • B) Enable DynamoDB Auto Scaling with a maximum WCU of 2000 and target utilization of 70%
  • C) Add a DAX cluster in front of DynamoDB
  • D) Manually increase WCU to 1500 immediately
Show Answer
B. Auto Scaling with target tracking automatically adjusts WCU based on consumption — handles spikes without code changes. Zero-cost when not scaling. On-Demand mode (A) is instant but more expensive per request at high throughput. DAX (C) only helps reads. Manual increase (D) requires ongoing management.

Mock Exam 4 — Migration & Modernization

75 Questions 180 Minutes Focus: 7 Rs, MGN, DMS, Modernization Patterns Difficulty: Medium-Hard
Q1
A company runs a Windows Server 2008 application that uses a proprietary driver not supported on newer OS versions. They want to migrate to AWS with the LEAST disruption. Which migration strategy is most appropriate?
  • A) Rehost — use AWS Application Migration Service (MGN) to lift-and-shift the Windows 2008 server as-is to EC2
  • B) Replatform — upgrade to Windows Server 2022 then migrate with MGN
  • C) Refactor — redesign the application to remove the proprietary driver dependency
  • D) Retire — move the workload to a SaaS replacement
Show Answer
A. The proprietary driver constraint means they cannot change OS versions. Rehost (lift-and-shift) moves the server exactly as-is to EC2. MGN supports Windows 2008. AWS has extended support for end-of-life Windows versions on EC2 for exactly this use case.

Mock Exam 5 — High Availability & Cost Optimization

75 Questions 180 Minutes Focus: DR Strategies, HA Patterns, Cost Tools, Pricing Models Difficulty: Professional
Q1
A company spends $400k/month on EC2. Cost Explorer shows 60% of the instances run at 25% CPU on average. AWS Compute Optimizer recommends downsizing. The fleet has mixed workloads: 40% run 24/7 (databases, always-on APIs), 30% run business hours only (batch, dev), 30% run sporadically (ML jobs, event processing). What combination of purchase options and actions maximizes savings? (Select THREE)
  • A) Downsize the 60% overprovisioned instances per Compute Optimizer recommendations
  • B) Purchase 3-year Compute Savings Plans for the 40% always-on workloads (highest discount)
  • C) Convert the 30% ML/event instances to Spot Instances (can be interrupted, not critical path)
  • D) Purchase 1-year Standard Reserved Instances for the 30% business-hours workloads
  • D2) Enable AWS Budgets alerts only — no other actions needed
Show Answer
A, B, and C. A: Right-sizing first — then commit to smaller instances. B: 3-year Compute SP for always-on = 66% discount, highest for flexible cross-family. C: Spot for ML jobs = 90% savings, acceptable for fault-tolerant workloads. D: Business-hours only = ~8 hours/day × 5 days = 33% utilization. RI (24/7 commitment) is wasteful for 33% utilization — better to use On-Demand or Spot Fleet.
