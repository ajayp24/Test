1. AWS Pricing Models Overview

AWS PRICING FUNDAMENTALS 1. PAY FOR WHAT YOU USE On-Demand: No commitment, highest price Pay by the hour or second 2. PAY LESS WHEN YOU RESERVE Reserved Instances: 1 or 3 year commitment Savings Plans: 1 or 3 year $/hour commitment Up to 72% discount vs On-Demand 3. PAY LESS BY USING MORE S3: Tiered pricing (more GB = lower $/GB) Data transfer: Volume discounts Consolidated billing: Combined usage for discounts 4. PAY EVEN LESS FOR SPARE CAPACITY Spot Instances: Up to 90% off On-Demand Interruptible when AWS needs capacity back

2. AWS Savings Plans

Savings Plans offer flexible pricing in exchange for a commitment to use a specific amount of compute power (measured in $/hour) for 1 or 3 years.

TypeApplies ToMax DiscountFlexibility
Compute Savings PlansEC2 (any family, size, OS, region), Lambda, FargateUp to 66%Highest (any instance, any region, any service)
EC2 Instance Savings PlansSpecific EC2 family in specific regionUp to 72%Limited (locked to family+region)
SageMaker Savings PlansSageMaker instancesUp to 64%Any SageMaker instance type
Savings Plans Recommendation: If you run a mix of EC2, Lambda, and Fargate across multiple regions, Compute Savings Plans give you the most flexibility. If you know you'll always use m5 in us-east-1, EC2 Instance SP gives slightly more discount.

RI vs Savings Plans: For most new workloads, AWS recommends Savings Plans over RIs due to flexibility. RIs can be sold on the Marketplace if no longer needed. Convertible RIs cannot be sold on Marketplace.

4. EC2 Spot Instances

SPOT INSTANCE ARCHITECTURE Normal Price: $0.25/hour (m5.xlarge) Spot Price: $0.025/hour (90% cheaper!) Spot Interruption: 2-minute warning before termination Triggered when AWS needs capacity BEST PRACTICES: 1. Spot Fleet: Mix instance types across AZs → If one type interrupted, another takes over 2. Mixed On-Demand + Spot ASG: Baseline: 20% On-Demand (stable) Burst: 80% Spot (cheap scaling) 3. Spot with SQS: Long job running? Checkpoint to SQS If interrupted, job restarts from checkpoint VALID SPOT USE CASES: ✓ Batch processing, data analytics ✓ CI/CD build servers ✓ ML model training ✓ Stateless web servers (in ASG) ✓ Image/video rendering INVALID SPOT USE CASES: ✗ Databases (stateful, needs persistence) ✗ Production single-instance web servers ✗ Any workload that cannot be interrupted

5. Cost Management Tools

AWS Cost Explorer

  • Visualize and analyze AWS costs and usage over time
  • Built-in filtering: by service, linked account, tags, Region, AZ
  • RI Recommendations: Suggests which RIs to purchase based on usage patterns
  • Savings Plans Recommendations: Recommends commitment amount based on historical usage
  • Forecast: Predict future costs based on historical trends
  • Granularity: Daily, monthly, hourly (with hourly granularity enabled)

AWS Budgets

  • Set custom cost/usage/RI utilization/Savings Plans thresholds
  • Alert when actual or forecasted costs exceed budget
  • Budget Actions: Auto-apply IAM policies or SCPs when budget exceeded (e.g., deny EC2 launch)
  • Types: Cost budget, Usage budget, RI utilization budget, Savings Plans utilization budget

6. AWS Compute Optimizer

Uses ML to analyze utilization metrics and recommend optimal AWS compute resources for EC2 instances, Auto Scaling Groups, EBS volumes, Lambda functions, and Fargate tasks.

COMPUTE OPTIMIZER RECOMMENDATIONS EC2: m5.4xlarge (current, 8% CPU avg) → m5.xlarge (23% CPU avg) Savings: -75% instance cost Lambda: 1024 MB memory (5% memory avg) → 256 MB memory Savings: -75% compute cost EBS: gp2, 3000 IOPS (100 IOPS actual avg) → gp3, 3000 IOPS No throughput change, lower cost Output: RIGHT_SIZED, OVER_PROVISIONED, UNDER_PROVISIONED

8. Cost Optimization Case Studies

Case Study: E-Commerce Platform — 40% Cost Reduction

COST OPTIMIZATION JOURNEY BASELINE: $200,000/month AWS spend STEP 1: Right-sizing (Compute Optimizer) Find 60 overprovisioned EC2 instances Average: m5.4xlarge → m5.xlarge or m5.2xlarge Saving: $40,000/month STEP 2: Savings Plans (Cost Explorer recommendation) Commit $50,000/month compute spend over 3 years Saving: $35,000/month (vs On-Demand) STEP 3: Spot Instances for batch jobs Move ML training, nightly reports to Spot 20 instances × 8 hours/night × On-Demand: $14,400/month Same with Spot: $1,440/month Saving: $12,960/month STEP 4: S3 Lifecycle Policies 50 TB of old log data in S3 Standard ($1,150/month) Move to S3 Glacier Deep Archive ($50/month) Saving: $1,100/month STEP 5: NAT Gateway optimization 20 TB/month cross-AZ traffic via NAT: $1,800/month Add S3/DynamoDB Gateway Endpoints (free) Saving: $600/month TOTAL SAVINGS: ~$90,000/month (45% reduction!)

9. Exam Tips & Cheat Sheet

SAP-C02 Cost Optimization — Critical Points

  • Savings Plans vs RI: Savings Plans = more flexible (any instance family/region, Lambda, Fargate). RI = slightly higher discount but less flexible. For most organizations → Savings Plans.
  • Compute Savings Plans: Most flexible — any EC2 family, any region, Lambda, Fargate. Slightly lower discount than EC2 Instance SP.
  • Spot Instances: Up to 90% off. 2-minute interruption notice. Only for stateless, fault-tolerant, batch workloads.
  • Spot Fleet: Diversify across instance types and AZs for Spot interruption resilience.
  • Compute Optimizer: Needs at least 30 days of metrics. Must be opted in. Recommends right-sizing.
  • Cost Explorer RI Recommendations: Based on last 7 or 30 days of usage. Review before purchasing RIs.
  • Budget Actions: Can automatically deny EC2 launches or apply IAM policies when budget exceeded — automated cost control.
  • Gateway Endpoints: Free. Use for S3 and DynamoDB to eliminate NAT Gateway data processing cost.
  • S3 Lifecycle: Auto-tier to Glacier Deep Archive for compliance archives — $0.001/GB vs $0.023/GB Standard.
  • Consolidated Billing: All accounts' usage aggregated for volume discounts. Reserved Instance sharing across accounts.
Purchasing Decision Tree
  • Steady workload, 1-3yr: Savings Plans or RI
  • Multi-service/region flexible: Compute SP
  • Specific EC2 family fixed: EC2 Instance SP
  • Batch/fault-tolerant: Spot
  • Variable/unpredictable: On-Demand
  • BYOL: Dedicated Host
Cost Tools Summary
  • Cost Explorer: visualize + analyze spend
  • Budgets: alert on threshold breach
  • Budget Actions: automated response
  • Compute Optimizer: right-sizing ML
  • Trusted Advisor: identify waste
  • Cost Anomaly Detection: ML-based alerts
Quick Wins
  • Unattached EBS → delete
  • Idle RDS → snapshot + delete
  • Old S3 Standard → Glacier lifecycle
  • NAT GW traffic → Gateway Endpoints
  • Large EC2 → right-size with Optimizer
  • Dev env → schedule stop nights/weekends
Data Transfer Costs
  • Inbound: Free
  • Same AZ EC2-to-EC2: Free
  • Cross-AZ: $0.01/GB each way
  • Cross-Region: $0.02/GB (varies)
  • Internet egress: $0.09/GB (first 10 TB)
  • CloudFront origin fetch: $0.02/GB
