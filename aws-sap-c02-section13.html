2. Exam Format

  • Questions: 75 total (65 scored + 10 unscored experimental)
  • Duration: 180 minutes (2h 30m) + 30 min for ESL accommodation if needed
  • Question types: Multiple choice (1 correct), Multiple response (2–3 correct from 5+)
  • Passing score: 750/1000 (scale score)
  • Delivery: Pearson VUE testing center or online proctored
  • Cost: $300 USD
  • Validity: 3 years

3. Question Analysis Framework

QUESTION ANALYSIS FRAMEWORK (5-Step Process) Step 1: READ THE STEM (question) • Identify the ACTUAL question (last sentence) • Note constraints: "most cost-effective", "LEAST operational overhead", "MINIMUM downtime", "MOST secure" Step 2: IDENTIFY KEY REQUIREMENTS • Technical constraints (latency, throughput, size) • Compliance requirements (HIPAA, PCI, GDPR) • Business constraints (budget, timeline) • Architecture requirements (HA, DR, multi-region) Step 3: ELIMINATE WRONG ANSWERS • Find options that contradict constraints • Eliminate services that don't apply • Watch for mismatched protocols or service scopes Step 4: COMPARE REMAINING OPTIONS • Between 2 similar options: which is MORE managed? • Which has LOWER operational overhead? • Which BEST fits the stated requirement? Step 5: ANSWER AND MARK FOR REVIEW IF UNSURE • Always answer (no penalty for wrong answer) • Flag uncertain questions for review • Don't change answers unless you find a clear reason

6. Common Exam Distractors

COMMON SAP-C02 TRAPS AND DISTRACTORS TRAP 1: "Multi-AZ for DR across regions" Reality: Multi-AZ protects against AZ failure, NOT region failure Correct: Need multi-region for regional DR TRAP 2: "Read Replica for HA" Reality: Read Replica ≠ HA (no automatic failover) Correct: RDS Multi-AZ for HA; Read Replica for read scaling TRAP 3: "SCP grants permissions" Reality: SCPs only RESTRICT, never GRANT Correct: IAM policies grant; SCPs limit the maximum TRAP 4: "Management account affected by SCPs" Reality: Management account is EXEMPT from SCPs Correct: SCPs apply only to member accounts TRAP 5: "NAT Gateway for S3 access" Reality: Use Gateway Endpoint (free!) for S3 from private subnet Correct: Gateway Endpoint → Route table entry → S3 TRAP 6: "DMS converts schema" Reality: DMS moves DATA; SCT converts SCHEMA Correct: Heterogeneous migration = DMS + SCT both needed TRAP 7: "CloudFront for TCP/UDP gaming" Reality: CloudFront = HTTP/HTTPS only Correct: Global Accelerator for TCP/UDP protocols TRAP 8: "Instance Store for persistent storage" Reality: Instance Store is EPHEMERAL (lost when instance stops) Correct: EBS for persistence; Instance Store for temp cache only TRAP 9: "S3 is global service" Reality: S3 bucket names are globally unique BUT buckets are REGIONAL Correct: Data doesn't replicate globally unless CRR configured TRAP 10: "Spot Instances for databases" Reality: Spot can be interrupted — terrible for databases Correct: Spot for batch/stateless; On-Demand/Reserved for DBs

7. Answer Elimination Strategy

4-STEP ELIMINATION FRAMEWORK For ANY scenario question, eliminate answers by: 1. WRONG SERVICE CATEGORY "Need to scan EC2 for CVEs" → Eliminate: GuardDuty, Macie, Detective → Only Inspector does vulnerability scanning 2. WRONG PROTOCOL/COMPATIBILITY "On-prem SMB Windows shares" → Eliminate: EFS (NFS only), FSx Lustre → Only FSx for Windows File Server supports SMB + AD 3. VIOLATES STATED CONSTRAINT "MINIMUM operational overhead" → Eliminate: self-managed on EC2 → Prefer managed services (RDS over EC2+MySQL) 4. WRONG SCOPE/BOUNDARY "Cross-REGION replication" → Eliminate: Multi-AZ (same region only) → Need CRR for S3, DMS cross-region, Aurora Global BETWEEN TWO SIMILAR ANSWERS: Managed vs self-managed → Managed (if "least overhead" constraint) More featured vs simpler → Depends on question constraints Expensive vs cheaper → Cheaper (if "cost-effective" constraint) Async vs sync replication → Sync for strongest consistency

Last-Minute Exam Tips

  • Read ALL answers before choosing — the BEST answer might be last
  • Watch for "EXCEPT" / "NOT" in questions — easy to miss
  • For multiple-response: count how many to select (usually "Select TWO" or "Select THREE")
  • Trust AWS best practices — more managed, more secure, more highly available is usually correct
  • When you see "compliance" + "audit" → CloudTrail + Config + Audit Manager
  • When you see "existing on-premises app" → look for hybrid solutions (Storage Gateway, Direct Connect)
  • When you see "reduce latency globally" → CloudFront (HTTP) or Global Accelerator (TCP/UDP)
  • When you see "cannot afford downtime" → Blue/green, Route 53 weighted, canary deployments
  • No negative marking — ALWAYS guess if unsure
  • Aim to finish 10 minutes early — use that time to review flagged questions
