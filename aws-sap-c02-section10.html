AWS Backup — Centralized Backup Management

  • Centrally configure and manage backup policies across EC2, RDS, Aurora, EFS, FSx, DynamoDB, EBS, S3
  • Backup Vault Lock: WORM (Write Once Read Many) — prevent backup deletion even by admin
  • Cross-account backup: Copy backups to different account (immutable DR copy)
  • Cross-region backup: Copy backups to different region
  • Integrates with Organizations for policy-driven backup across all accounts

8. Exam Tips & Cheat Sheet

SAP-C02 HA & DR — Critical Points

  • RTO vs RPO: RTO = how long can we be down? RPO = how much data can we lose?
  • Backup & Restore: Cheapest. Slowest (hours). Snapshots stored cross-region.
  • Pilot Light: DB replica running, EC2 not running. Fast DB recovery, slow app recovery.
  • Warm Standby: Scaled-down copy running in DR. Scale up on disaster. Minutes RTO.
  • Active/Passive: Full capacity in DR, Route 53 failover routing. Minutes RTO with Aurora Global.
  • Active/Active: Both regions serve traffic. Route 53 latency/weighted routing. DynamoDB Global Tables (multi-active writes). Near-zero RTO/RPO.
  • Aurora Global Database: RPO ~1 sec, RTO ~1 min. Best for active/passive cross-region.
  • DynamoDB Global Tables: Multi-active. Any region can write. Use for active/active.
  • Route 53 Failover: Health checks detect failure. TTL affects switchover speed — use low TTL (30-60 sec) for DR.
  • AWS Backup Vault Lock: WORM backups — even admins can't delete. For compliance.
  • RDS Read Replica promotion: Manual action required. Plan DR procedure and automate it.
DR Strategy Summary
  • Backup: Hours RTO/RPO, cheapest
  • Pilot Light: 10-60min RTO, DB running
  • Warm Standby: minutes RTO, scaled-down
  • Active/Passive: min RTO, full DR region
  • Active/Active: seconds RTO, both live
Key DR Services
  • Aurora Global: RPO <1s, RTO <1min
  • DynamoDB Global Tables: multi-active
  • Route 53 Failover: automatic routing
  • S3 CRR: async object replication
  • AWS Backup: centralized snapshots
HA Patterns
  • Multi-AZ = AZ-level HA
  • Multi-Region = Region-level HA
  • Auto Scaling = compute HA
  • ALB health checks = traffic HA
  • RDS Multi-AZ = DB AZ-level HA
RPO/RTO Quick Math
  • Daily backup = RPO up to 24 hours
  • Hourly backup = RPO up to 1 hour
  • Async replication = RPO minutes
  • Aurora Global = RPO <1 second
  • Manual restore = RTO hours
  • Route 53 failover = RTO minutes
